# EducaIbiapaba

Sistema de análise e comparação de indicadores educacionais dos municípios da Serra da Ibiapaba, Ceará.

## Objetivo

O EducaIbiapaba tem como objetivo organizar, analisar e apresentar dados educacionais oficiais, permitindo acompanhar indicadores como a taxa de abandono escolar e comparar resultados entre municípios e redes de ensino.

## Municípios contemplados

- Ibiapina
- São Benedito
- Tianguá
- Ubajara

## Tecnologias

- **Python:** processamento e análise de dados.
- **Pandas:** limpeza, organização e validação dos dados.
- **PostgreSQL:** armazenamento dos dados.
- **FastAPI:** desenvolvimento da API.
- **HTML, CSS e JavaScript:** interface web.

## Fontes de dados

- [Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira (Inep)](https://www.gov.br/inep/)
- [Instituto Brasileiro de Geografia e Estatística (IBGE)](https://www.ibge.gov.br/)
